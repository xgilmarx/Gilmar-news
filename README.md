# Gilmar News 📱

Aplicação pessoal para reunir num só lugar notícias, oportunidades, promoções, viagens, carros, eventos, finanças e alertas importantes.

## Versão atual
Protótipo web responsivo, feito com HTML, CSS e JavaScript.

### Executar
Abra `index.html` num navegador.
